这是一个纯 HTML + 内联 SVG + 原生 JavaScript 的单文件 2D 动画，无需任何外部依赖，双击即可打开。


画面与动画包含：

鹈鹕蹬车动作：根据脚踏位置实时计算双腿关节角度
车轮、牙盘、脚踏和链条同步转动
珊瑚色长围巾随风飘动
海边遮阳帽般的暖阳、云朵、海鸥、帆船与灯塔
海面、步道和前景植物的多层视差滚动
眨眼、身体起伏等细节循环
点击右下角按钮或按空格键可暂停 / 播放
响应式适配：手机竖屏时自动缩小骑行者，保证整辆车完整入镜
支持 prefers-reduced-motion，尊重系统的减少动画偏好
预览图preview.png为静止截图，实际打开index.html后即为持续循环动画。
